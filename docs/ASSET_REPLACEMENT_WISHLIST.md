## Albany: exactly what is missing

The approved **historical Albany Kneelers helmet already exists**, as does the
2021 championship artwork. No verified historical helmet is fabricated or
silently substituted. The profile now explicitly says it features the archived
Kneelers helmet and keeps the accurate image alt text. The current canonical name
is Albany Redskins, while Yahoo historical names verify Kneelers in 2025.

Needed: a commissioner-approved **current-name Albany Redskins helmet/logo**, its
intended seasons/effective date, and preferably the higher-resolution original of
the existing Kneelers seal/helmet for archival uses. If a different missing
historical era was intended, supply that exact era and approved source before any
change. A current-name image must not rewrite older season identity artwork.

## Crops, sizing and delivery

Identity art, source captures, brackets, trophy and honors use contain/full-image
presentation. Only decorative venue backdrops and short directory venue strips
use cover cropping; full uncropped venue images remain in linked profile galleries.
The source resolution cannot be improved by CSS. Fixed image frames reserve layout
space; explicit dimensions are added where the source is known, and below-fold
images retain native lazy loading. No lossy image work is needed for launch.

The two largest PNG originals remain a page-weight limitation, documented rather
than silently lowering their quality. Native lazy loading defers below-fold art,
but it does not shrink the bytes when readers scroll to it. Page scripts remain
local; the countdown now loads only on the homepage that uses it.

### Measured display and page weight

At the reviewed widths, non-decorative enlargements included the 2022 standings
capture at 1.46× intrinsic size, Baseball Furies' venue at 1.41×, the 2021/2022
brackets at 1.37×/1.35×, and Van Cortlant's venue at 1.30×. These are replacement
priorities, not sharpened/upscaled deliverables. Approved helmets stayed within
their intrinsic dimensions at the measured CSS sizes; high-density screens still
benefit from better originals. Decorative venue heroes can enlarge/crop further.

Uncompressed full-visit estimates (HTML plus each referenced local image/script/
stylesheet once, including below-fold images) are approximately 1.47 MiB for home,
3.50 MiB for Teams, 4.08 MiB for Draft Archive, and 3.85 MiB for the 2025 draft.
These are not initial-load transfers, Lighthouse scores, or promises about server
compression. The largest draft PNG dominates its pages. No runtime dependencies
were added to chase a synthetic performance score.
